# Programacion2

Repositorio de tareas de Programación 2 con ejercicios en Java.

## Contenido

Los archivos `.java` de la raíz contienen ejercicios de listas, ingreso de datos, búsqueda, tareas, números y promedios.

## Ejercicio de ramas en GitHub

| Rama de creación | Archivo solicitado |
| --- | --- |
| `feature/documentacion` | `README.md` |
| `bugfix/documentacion` | `DocumentacionSolucion.txt` |
| `hotfix/documentacion` | `DocumentacionSolucionhotfix.txt` |

La práctica consiste en crear las tres ramas remotas desde `main`, registrar cada archivo mediante un commit, integrar los cambios en `main` y sincronizar las ramas.

Los prefijos `feature/`, `bugfix/` y `hotfix/` se completan con `documentacion`, porque un nombre de rama no puede terminar en `/`.

Consulta [la documentación del proceso](DocumentacionRamas.md) para ver los comandos equivalentes y la evidencia del historial remoto.
